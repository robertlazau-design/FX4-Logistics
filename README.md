# FX4 Logistics website

Website for FX4 Logistics Inc., trucking and warehousing in Wood Village, Oregon. Built by Golden Boy Productions.

**Status:** draft preview. Search engines are kept out until launch; see `CLAUDE.md` for the launch checklist.

```bash
npm install
npm run dev     # local server at http://localhost:3000
npm run build   # build + prerender to dist/
npm run lint    # type-check
```
